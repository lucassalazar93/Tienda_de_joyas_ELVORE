# ELVORÉ — Prototipo premium

HTML, CSS y JavaScript estáticos. Sin npm install ni compilación.

## Local
Abrir index.html, o ejecutar `py -m http.server 8000` y visitar http://localhost:8000.

## GitHub y Vercel
1. Crear un repositorio privado llamado elvore.
2. Subir el contenido de esta carpeta en la raíz del repositorio, incluido assets/ y vercel.json.
3. En Vercel, importar el repositorio de GitHub.
4. Framework Preset: Other. Root Directory: raíz del repositorio. Build Command: vacío. Output Directory: .
5. Desplegar. No hacen falta variables de entorno.

Vercel Hobby está reservado para uso personal no comercial. Confirmar elegibilidad del proyecto; un prototipo para cliente no es automáticamente elegible. No se ha contratado ningún plan ni desplegado este paquete.

## Edición
